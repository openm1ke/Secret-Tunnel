# Android: экраны и профили

Главная показывает честное состояние соединения, один основной следующий шаг, выбранный профиль, скорости загрузки/отправки, суммарный трафик и график последних 60 секунд. История собирается в VPN-сервисе и сохраняется при переходах между экранами и открытии других приложений. Скорости вычисляются по монотонному времени; сброс счётчиков и возвращение после длинного фонового интервала не создают ложных пиков.

Серверы содержат название, SSH-адрес, порт, пользователя, свой зашифрованный ключ и доверенный SHA256. Старые настройки автоматически переносятся в основной профиль без расшифровки/копирования ключа в другие профили. Смена адреса/порта сбрасывает доверие. Изменившийся ключ никогда не принимается молча.

Прокси — именованный локальный SOCKS5-профиль: сервер и порт 1024–65535 на 127.0.0.1. Одновременно активен один профиль. Удалить сервер, на который ссылается прокси, нельзя. Изменение подключения требует остановки VPN. Сервис фиксирует сервер, ключевой профиль, отпечаток, порт и список приложений на весь сеанс; переподключение не переключается на другой сохранённый профиль.

Приложения показываются с настоящими иконками и переключателями. Есть поиск и просмотр выбранных. Список использует переиспользуемые строки ListView; listener переключателя отключается перед повторным заполнением, чтобы прокрутка не меняла настройки. Кэш иконок ограничен 32 элементами. Новая выборка применяется после переподключения.

Журнал отделён от основного экрана, ограничен по объёму, поддерживает копирование пользователем. Приватные ключи и пароль в журнал не записываются.

Проверки: TrafficMeterTest (скорости, сбросы, фоновые интервалы); ProfileTest (миграция, изоляция ключей/отпечатков, ссылки, снимок сеанса, разные порты); NavigationTest (экраны и повторное создание строк переключателей); ConnectionTest (реальный SSH и регистрация ключа). Сетевой тест выполняется отдельным приложением через профиль на локальном порту 1081.
