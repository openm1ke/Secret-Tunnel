# Аудит desktop-клиента и адаптация macOS — 8 ноября 2026

База: `ed6979e`, ветка `main`; `git pull --ff-only` — `Already up to date`. Работа выполнена в `codex/macos-app-routing`. Проверены desktop UI/Rust, общий код SSH/SOCKS/UDP и серверный агент. Android-интерфейс и сборка APK в этот аудит не входят. Это проверка исходников и интеграции, не полный пентест.

## Исправлено

- Windows-only каталог и запуск перехвата заменены платформенной интеграцией: macOS `.app`/`.xpc`, точные ID, собственный формат CLI-профиля ProxyBridge, состояние запуска/ожидания разрешения, корректный Stop/parent EOF. Функциональность реально проверена на Mac, а не только с моками IPC.
- Весь предоставленный набор Discord из пяти процессов включается одним выбором; каждый ID сверен с фактической подписью executable. Общее имя standalone-утилиты `ShipIt` автоматически не захватывается; для ручного правила показан побочный охват других Electron-утилит.
- Embedded SSH отклонял существующий доверенный ключ на нестандартном порту, если запись `known_hosts` была по имени хоста без порта. Воспроизведено: свежий OpenSSH с `StrictHostKeyChecking=yes` аутентифицировался, Embedded — нет. Добавлена совместимость с host-wide записью только при отсутствии port-specific записи. Изменённая scoped-запись продолжает отклоняться; unknown host и pin mismatch — тоже. Host-key checking не отключался, `known_hosts` не переписывался.
- Неаутентифицированный SOCKS теперь ограничен literal loopback-адресами. Раньше профиль мог открыть его на `0.0.0.0`/внешнем интерфейсе.
- Аргументы OpenSSH отделены от destination через `--`; host/user с начальным дефисом или управляющими символами отклоняются.
- Опрос UI защищён от перекрывающихся запросов. При обнаружении завершения SSH останавливается и процесс перехвата.
- Vite обновлён с 5.x до 6.4.5, plugin-react — до 4.7, транзитивные зависимости исправлены. `npm audit`: было 7 уязвимых пакетов (5 high, 2 moderate), стало 0. Это не означает отсутствие уязвимостей Rust или приложения в целом.
- Найдена причина падения UDP echo-теста на macOS: штатный `net.inet.udp.maxdgram=9216` не допускает отправку 51200 байт. Тест использует 8192 байта на Mac и 51200 на других ОС; системные ограничения не менялись.

## Оставшиеся находки

| Приоритет | Находка и последствия | Следующий шаг |
| --- | --- | --- |
| P1 | Нет независимого kill switch. После остановки/аварии выбранные приложения могут подключиться напрямую. Это явно отражено в UI/документации. | Отдельная системная политика блокировки, проверенная при авариях/сне/смене сети. |
| P1 | Reconnect по-прежнему зависит от `tunnel_status`: ожидание delay и одна попытка запуска происходят в запросе статуса. После неудачи supervisor повторов отсутствует; отмена ожидания не реализована. | Фоновый supervisor с отменой, backoff и состояниями reconnecting/failed. |
| P2 | `save_config` делает прямой `fs::write`: авария может повредить JSON. Конкурирующие read-modify-write команды не сериализованы. | Atomic replace, единый владелец конфигурации и проверка восстановления. |
| P2 | IPinfo token хранится в JSON и передаётся `curl` в URL-аргументе процесса. Маскирование UI не защищает файл и process list. | Хранилище секретов ОС и передача токена без argv. |
| P2 | `EmbeddedServer` не содержит compression/connect_timeout/keepalive из профиля; embedded handshake использует собственные фиксированные значения. `verify_proxy_on_start` и `test_server` не полностью соответствуют выбранному движку. | Общие параметры/проверка выбранного движка и корректные подсказки UI. |
| P2 | Статус удерживает runtime mutex во время измерений и IPinfo; один poll может задержать команды. Защита frontend от наложения уменьшает очередь, но не заменяет фоновую телеметрию. | Независимые sampler/IP cache и быстрый снимок состояния через IPC. |
| P2 | macOS-профиль пока не использует DNS proxy. Системный DNS может идти напрямую; Windows domain regex-правила на Mac явно не запускаются. | Отдельная DNS-политика и совместные тесты с fake-IP DNS, DoH, IPv6, другими VPN. |
| P2 | Подписи самостоятельных Electron-утилит (`ShipIt`, `chrome_crashpad_handler`) не уникальны для Discord. Текущий ProxyBridge не поддерживает ограничение по полному пути/Team ID. | Path/signing-requirement matching в расширении либо осознанное общее правило. |
| P2 | В Tauri по-прежнему `csp: null`. | Ограничить CSP с проверкой production IPC и стилей. |

Предыдущий аудит от 7 ноября содержал уже исправленные пункты: embedded readiness/lifecycle, full-duplex forwarding и системные счётчики. Повторно выдавать их за актуальные дефекты нельзя: теперь есть канал готовности/исхода, независимые copy loops и локальный traffic relay.
