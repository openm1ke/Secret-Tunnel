Secret Tunnel 0.3.24 добавляет обновление приложения и серверного агента из раздела «О программе».

- На macOS и в установленной версии Windows можно скачать новую версию, проверить её по SHA-256 и установить с перезапуском. Портативная версия Windows открывает страницу релиза.
- Из того же раздела можно проверить версию агента, установить его на чистый сервер или заменить установленный. Приложение скачивает агент своей версии и передаёт его по SSH. Установщик проверяет агент и сохраняет предыдущий бинарник для отката.
- Справка по установке и база знаний доступны внутри приложения. Поиск работает и во встроенной копии без доступа к GitHub.
- В разделе «Приложения» появились плитки, таблица и карточки. В подробных видах видны трафик и дата включения приложения в туннель.

Для первого перехода с 0.3.23 скачайте сборку ниже. После обновления приложения установите агент 0.3.24 на конечном SSH-сервере.

В релизе доступны подписанный APK Android, установщик и портативный ZIP Windows, универсальные DMG и ZIP macOS, архив агента Linux x86_64 и контрольные суммы SHA-256.
