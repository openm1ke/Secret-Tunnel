Secret Tunnel v0.2.3 introduces a shared, bounded TCP/UDP transport for Android, Windows and macOS.

- **One SSH channel:** STMUX003 carries all application TCP and UDP flows through one server-agent process. The earlier per-association exec implementation reproducibly stopped at 10 UDP associations on a default OpenSSH server. The new transport has been tested with 2048 simultaneous TCP connections through real SSH, followed by 64 UDP associations alongside an exact 8 MiB transfer and a stalled consumer.
- **Bounded resources:** consumption-based credit isolates slow flows; TCP preserves bytes and half-close. Batched writes reduce transport calls. Queue limits, connection admission and counted UDP overload avoid unbounded buffering. Android devices with at least 6 GiB physical RAM request up to 2048 flows; the server negotiates its available capacity. Expanded/virtual RAM is not counted.
- **Update both sides:** install the included Linux server agent at `~/.local/bin/secret-tunnel-agent` before connecting the new embedded client. The new client requires `--stdio-v3` / STMUX003 and fails clearly with an old agent. No sshd change, public agent port or system service is required. The agent retains older modes to allow existing clients to migrate.
- **Android media:** IPv6 is advertised only after an authenticated egress probe succeeds; otherwise the VPN uses IPv4 and blocks IPv6 bypass. On Android 10+, metered status follows the underlying network. TCP uses a 64 KiB native buffer and bounded setup; UDP idle timeout is 60 seconds.
- **Diagnostics:** client/server queue usage, negotiated capacity, peak flows, rejects, protocol failures and UDP drops are available in Android diagnostics. Traffic probes exercise ordinary per-UID Android sockets, not a proxy-only test.

Downloads include a signed Android APK, Windows setup/portable, macOS universal DMG/ZIP, a Linux x86_64 agent and SHA256SUMS.txt. Android signing is compatible with earlier releases. macOS uses an ad-hoc signature without Apple notarization and requires separately installed official ProxyBridge for per-app interception. Synthetic and emulator checks do not establish physical realme/Instagram behavior, mobile handover or performance under arbitrary packet loss; see the repository's transport validation report.
