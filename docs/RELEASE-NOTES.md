В Secret Tunnel 0.3.32 появился мастер настройки SSH-подключения.

- Откройте «Серверы» → «Мастер настройки». На Android и iOS раздел «Серверы» находится в меню «Ещё».
- Укажите адрес, SSH-порт и пользователя. Выберите готовый приватный ключ либо введите пароль от сервера: приложение создаст отдельный Ed25519-ключ, добавит публичную часть на сервер и проверит повторный вход по ключу. Пароль не сохраняется.
- Перед отправкой данных подтвердите отпечаток сервера. Журнал мастера показывает текущий этап и причину ошибки; после исправления данных можно повторить попытку.
- Мастер проверяет серверный агент и при необходимости предлагает его установку с проверкой SHA-256. Поддерживаются серверы Linux x86_64, обычный вход SSH по паролю и ключи без парольной фразы.
- Экспериментальная версия iOS хранит несколько серверов с отдельными ключами. Для переключения остановите VPN и нажмите «Использовать» у нужного сервера.

Для телефона предназначен `SecretTunnel-0.3.32-android.apk`, для телевизора — `SecretTunnel-0.3.32-android-tv.apk`. iOS собирается отдельно и не входит в общий набор публичных релизов.

Обновите агент на конечном SSH-сервере до 0.3.32 вместе с приложением. Его можно установить из мастера или раздела «Агент на сервере».
