В Secret Tunnel 0.3.30 появился отдельный подписанный APK для Android TV.

- В ТВ-версии все разделы доступны из вертикального меню. При проверке версии агента фокус остаётся на кнопке. Журнал прокручивается стрелками пульта, а переключатели и списки выделяются рамкой.
- Исправлен запуск VPN на приставках с 32-битным ARM. Android показывает ошибку загрузки нативных библиотек и последний этап запуска после неожиданного завершения.
- Для телефона скачайте `SecretTunnel-0.3.30-android.apk`, для приставки или телевизора — `SecretTunnel-0.3.30-android-tv.apk`. При переходе с локальной сборки test5 настройте профиль заново в релизном приложении. [Установка на Android TV](https://openm1ke.github.io/Secret-Tunnel/guide.html#android-tv)

Обновите агент на конечном SSH-сервере до 0.3.30 вместе с приложением. Агент можно установить из раздела «Агент на сервере».
