Secret Tunnel 0.3.29 исправляет проверку SSH-серверов на macOS, Windows и Android.

- На macOS и Windows кнопка «Проверить SSH» показывает результат или ошибку по таймауту. Управление подключением остаётся доступным во время проверки.
- На Android можно проверить сохранённый сервер, отпечаток и агент при активном VPN. Результат появляется под кнопками проверки.

Агент 0.3.29 для конечного SSH-сервера доступен в этом релизе. Установить его можно в разделе «Агент на сервере».
