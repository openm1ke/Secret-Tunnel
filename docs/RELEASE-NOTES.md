Secret Tunnel v0.2.3 improves parallel media traffic on Android and shares the corrected UDP transport with Windows and macOS.

- **Parallel UDP:** the updated server agent multiplexes independent UDP associations over one SSH channel. The previous implementation opened one SSH exec session per association and reproducibly failed after 10 simultaneous associations on a default OpenSSH server (10 replies from 24 attempts).
- **Flow isolation:** each association has its own identifier and server-side source socket, including when different applications contact the same destination. Closing one association does not close others. Queues and flow counts remain bounded.
- **Compatibility:** old clients continue to use STUDP001. New clients negotiate STUDP002 using `--multiplex`; with an old agent they retain legacy behavior and show an update warning in diagnostics. Update the user-owned server agent to gain the parallel-UDP fix; no SSH daemon configuration or public UDP listener is required.
- **Android IPv6:** the client probes IPv6 egress through authenticated SSH before exposing IPv6 routes. If neither probe succeeds, it uses IPv4 and blocks IPv6 inside the VPN rather than letting it bypass the tunnel. This avoids advertising IPv6 connectivity that the SSH server cannot provide.
- **Android media policy:** the VPN inherits the underlying network's metered status instead of always reporting a metered connection on Wi-Fi. The native TCP buffer uses the upstream 64 KiB default; idle UDP sessions expire after 60 seconds instead of retaining the TCP timeout of five minutes. TCP destination setup has a bounded timeout with a SOCKS failure response.
- **Validation tools:** protocol and routing tests cover concurrent independent UDP associations, reordered replies, close isolation and agent failure. The Android traffic probe can test 24 concurrent UDP sources plus four parallel 2 MiB HTTPS downloads using ordinary application sockets.

Downloads include a signed Android APK, Windows setup/portable, macOS universal DMG/ZIP, a Linux x86_64 agent and SHA256SUMS.txt. Android signing is compatible with earlier releases. macOS uses an ad-hoc signature without Apple notarization and requires separately installed official ProxyBridge for per-app interception. Physical-device Instagram loading and cellular/Wi-Fi handover still need confirmation; synthetic probes do not establish that every CDN or media format works.
