Secret Tunnel 0.3.37 добавляет каталог хостеров с проверкой задержки из вашей сети.

- Отдельный экран на macOS, Windows, Android и Android TV: страны, флаги локаций, месячные цены, CPU/RAM/диск, условия трафика и ссылки на провайдеров.
- Семь хостеров: OVHcloud, ITLDC, Timeweb Cloud, FirstVDS, IPHoster, Vultr и Hetzner. Данные обновляются ежедневно через GitHub Actions отдельно от приложения.
- «Проверить задержку» выполняет пять коротких TCP-подключений. Можно фильтровать страны, сортировать и отменять проверки. Тарифы без подтверждённого тестового узла остаются в списке без сетевого замера.
- «Сайт хостера» открывает сайт провайдера, а «Сервер уже куплен — настроить SSH» возвращает в мастер. Тестовые IP не становятся SSH-профилями.
- Последняя корректная копия сохраняется при ошибках; у неподтверждённого тарифа остаётся прежняя дата проверки. Каталог не меняет ключи и настройки подключения.

Задержка TCP не является ICMP-пингом или гарантией скорости VPS. Финальные цены, налоги, доступность оплаты и ресурсы уточняйте у хостера. При активном туннеле приложения замер блокируется; перед остановкой туннеля закройте защищаемые программы.

В экспериментальном iOS-клиенте есть тот же каталог с интерфейсом для iPhone/iPad. Пакет iOS в публичный релиз не входит.

Проверены адаптеры, валидация и кэш, отмена, публикация сайта и сохранность настроек; сборки desktop/mobile, обновление каталога и реальные TCP-подключения на iPad Simulator.

**Обновите приложения и агент на конечном SSH-сервере до 0.3.37: они используют общую версию.**

В релиз входят macOS universal (Apple Silicon и Intel), Windows x64 (установщик и portable), Android, Android TV и агент Linux x86_64.
