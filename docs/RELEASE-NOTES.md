В Secret Tunnel 0.3.28 появились светлая и тёмная темы. Системная тема включена по умолчанию и меняется вместе с оформлением устройства. Ручной выбор применяется сразу и сохраняется после перезапуска.

- macOS и Windows — «Настройки» → «Оформление» → «Тема».
- Android — «Ещё» → «Настройки» → «Оформление».
- На сайте переключатель темы находится в шапке. Выбор действует на всех страницах.

После обновления приложения установите агент 0.3.28 на конечном SSH-сервере. Это можно сделать в разделе «Агент на сервере».
