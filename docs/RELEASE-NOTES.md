В Secret Tunnel 0.3.25 появился раздел «Ещё» → «О программе» для Android.

- Проверяйте обновления при запуске приложения или вручную. Раздел показывает версию, список изменений и ход загрузки. Перед установкой приложение проверяет SHA-256, версию и подпись APK. Установку подтверждает пользователь в диалоге Android.
- Проверяйте версию серверного агента и устанавливайте агент для Linux x86_64 через настроенную цепочку SSH. Приложение скачивает архив своей версии и проверяет его перед отправкой.
- Инструкция по установке и база знаний доступны в приложении. Поиск работает и во встроенной офлайн-копии.

Для первого перехода с Android 0.3.24 скачайте подписанный APK на этой странице. После обновления клиента установите агент 0.3.25 на конечном SSH-сервере.
