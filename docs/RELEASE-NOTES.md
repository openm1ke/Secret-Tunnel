Secret Tunnel 0.3.34 исправляет запуск обновлений в Windows.

**Если прежняя версия скачала установщик и закрылась, но установка не началась, скачайте `SecretTunnel-0.3.34-windows-x64-setup.exe` из этого релиза и один раз запустите его вручную поверх текущей установки. Настройки, серверы и SSH-ключи очищать не нужно. Исправленный механизм будет использоваться при следующих обновлениях.**

- Приложение закрывается только после подтверждения готовности помощника и повторной проверки SHA-256 установщика. Ошибка запуска или таймаут оставляют приложение открытым.
- Помощник использует модули системного PowerShell 5.1 независимо от окружения PowerShell 7, из которого могло быть запущено приложение.
- Установщик получает независимую копию файла, показывает прогресс и использует исходный каталог установки.
- После успешной установки приложение открывается снова. При отказе помощник сохраняет причину и пытается открыть доступную установленную версию. Ошибка видна после запуска и в разделе «О программе».
- Диагностика обновлений сохраняется в `%APPDATA%\secret-tunnel\updates`.

Проверены успешная замена тестового EXE, отказ установщика, неверная контрольная сумма и сохранность конфигурации в Windows 11 с PowerShell 5.1. Проверки используют изолированный тестовый установщик; пользовательская копия приложения не переустанавливается.

В релиз также входят macOS, Android, Android TV и Linux x86_64 агент с общей версией 0.3.34. После обновления клиента обновите агент на конечном SSH-сервере до 0.3.34 через раздел «Агент на сервере».
