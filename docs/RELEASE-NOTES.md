В Secret Tunnel 0.3.26 Android автоматически восстанавливает SSH после смены Wi‑Fi и мобильной сети.

- На экране «Приложения» галочка «Блокировать при обрыве туннеля» перекрывает прямой доступ отмеченной программе, пока Android держит VPN. Чтобы применить настройку, перезапустите туннель вручную.
- При смене сети встроенный тест скорости прерывается, а приложение продолжает работать. После восстановления туннеля можно запустить новый замер.
- На macOS, Windows и Android 10+ профиль «Голос» поддерживает «Отдельный SSH для UDP». Включите эту настройку и отметьте «UDP через второй SSH» для приложений звонков. Если второй сеанс оборвётся, новые UDP-соединения пойдут через основной.
- Экран подключения показывает состояние SSH и перехвата отдельно. Можно проверить TCP, UDP, DNS и IPv6 через SOCKS. На Windows ProxyBridge подхватывает трафик Dorion через проверенные дочерние процессы WebView2.

После обновления клиента установите агент 0.3.26 на конечном SSH-сервере. Это можно сделать в приложении из раздела «Агент на сервере».
