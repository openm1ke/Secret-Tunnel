# Secret Tunnel для Windows

Рекомендуется установщик `windows-x64-setup.exe`: он содержит приложение, комплект перехвата и offline-установщик Microsoft WebView2. Portable ZIP содержит приложение и весь комплект перехвата; для него необходим уже установленный WebView2 Runtime (обычно есть в актуальной Windows 10/11).

1. Установите приложение либо распакуйте ZIP целиком. Для перехвата приложений запустите Secret Tunnel **от имени администратора**.
2. Укажите ваш SSH-сервер, пользователя и приватный ключ. Свежая полная сборка использует Embedded Rust SSH — системный OpenSSH для TCP/UDP не требуется.
3. Запустите туннель, выберите приложения и/или доменные правила, затем включите перехват. Переподключите приложения, чьи старые соединения были открыты до перехвата.

Комплект `tools/proxybridge` обнаруживается рядом с EXE автоматически. Пользовательские настройки находятся в `%APPDATA%\secret-tunnel`; никаких SSH-ключей или параметров конкретного сервера в дистрибутиве нет. Старый явно заданный путь движка можно заменить в разделе «Приложения → Дополнительно».

Для TCP и UDP встроенного движка на Linux x86_64 сервере скопируйте каталог `server` в домашний каталог своего SSH-пользователя и выполните `sh install-server-agent.sh`. Агент устанавливается в `~/.local/bin`, запускается по SSH по требованию и не меняет Xray/wstunnel/службы/фаервол. Для другой архитектуры соберите crate `udp-agent` из исходников.

В поставке: ProxyBridge CLI и Core DLL с патчами остановки/доменных regex, WinDivert DLL и исходный подписанный WinDivert64.sys, лицензии, SHA256-манифест и серверный UDP-agent. Драйвер проверяется по подписи и закреплённым SHA256 при сборке; защита Windows не отключается. Приложение и установщик сейчас без коммерческой Authenticode-подписи, поэтому Windows может показать предупреждение о неизвестном издателе.

Доменные правила определяют домен по обычному DNS; DoH/DoT и общие IP ограничивают точность. Счётчики доменов отражают решения маршрутизации, не гарантированную доставку. Подробности в документации репозитория.
