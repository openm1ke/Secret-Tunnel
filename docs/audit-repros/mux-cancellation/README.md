# Отмена потока v3: регрессионные воспроизведения

На исходном `da9ab22`, Linux/WSL, 9 ноября 2026, оба теста падали и подтверждали A1/A2 в [аудите](../../AUDIT-2026-11-09.md). После исправлений в рабочей ветке оба проходят. Это изолированный диагностический crate, не часть релизной сборки; основные регрессии уже добавлены в `stream-mux/src/tests.rs` и выполняются в CI.

Запуск из корня репозитория:

```bash
CARGO_TARGET_DIR=/tmp/secret-tunnel-audit cargo test --manifest-path docs/audit-repros/mux-cancellation/Cargo.toml --locked
```

Сеть и сервер не требуются: используются настоящий Endpoint и настоящий relay с ограниченными in-memory duplex-потоками Tokio.

1. Получатель остаётся подключённым, но перестаёт читать; 16 КиБ заполняют его буфер. В исходном коде active уже становился 0, но relay оставался в write_all. Теперь отмена прерывает локальный IO, а слот освобождается при завершении владельца Flow, после освобождения его ресурсов.
2. В исходном коде Sender.is_closed() уже true, но поздний Sender.closed() не завершался: watch::Sender::send не сохранял значение без подписчиков. Теперь терминальное значение сохраняется через send_replace.

Дополнительно проходят 1000 циклов с блокированным duplex-получателем, 200 циклов с настоящими loopback TCP-сокетами в обеих ролях и остановкой Endpoint. Тест отмены зависшего настоящего SSH handshake находится в `embedded_ssh::platform_tests`. Длительные проверки RSS/PSS/FD и реальной сети остаются в плане. Таймауты тестов — дедлайны наблюдения, не политика TCP idle timeout.
