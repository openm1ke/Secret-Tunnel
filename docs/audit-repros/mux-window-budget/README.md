# Окно потока, бюджет приёма и срабатывание QoS: стенд мультиплексора

Изолированный диагностический crate для [независимого аудита](../../CLAUDE-INDEPENDENT-AUDIT.md). Он не входит в релизную сборку и не меняет рабочий транспорт. Сеть, SSH и сервер не нужны: две настоящие `Endpoint` из `stream-mux` соединены каналом в памяти с фиксированной задержкой в одну сторону, без ограничения скорости и без потерь.

Запуск из корня репозитория:

```bash
CARGO_TARGET_DIR=/tmp/secret-tunnel-audit cargo run --release --locked \
  --manifest-path docs/audit-repros/mux-window-budget/Cargo.toml -- all
```

Вместо `all` можно указать один режим.

| Режим | Что показывает |
|---|---|
| `window` | Скорость TCP-загрузки одного и четырёх потоков при RTT 20–200 мс для окна приёма 64 КиБ (как в релизе), 256 КиБ и 1 МиБ. Последний столбец — расчёт `64 КиБ / RTT × число потоков`. |
| `qos` | Восемь TCP-загрузок при RTT 50 мс. На пятой секунде клиент один раз отправляет 12 коротких датаграмм: как шесть DNS-запросов на шести потоках и как один голосовой поток. На `v0.3.6` оба случая ограничивали весь TCP на 15 секунд; после исправления 11 ноября 2026 ограничивает только голосовой поток. |
| `budget` | Сколько простаивающих UDP-потоков открывается до первого отказа для профилей Android, desktop и iOS, и принимается ли после этого TCP. |

Результаты прогона 10 ноября 2026 (macOS 27.2.1, Apple M4) сохранены в [JSON](../../benchmarks/claude-audit-2026-11-10.json), раздел `mux_stand`.

Режим `budget` показывает состояние текущего кода. На `v0.3.6` отказ наступал на четверти или половине лимита (128 потоков из 512 для Android). После исправления бюджета 11 ноября 2026 каждый профиль открывает столько UDP-потоков, сколько заявлено в лимите; эти результаты лежат в разделе `after_budget_fix_2026-11-11`. Чтобы увидеть прежнее поведение, запустите стенд на коммите `v0.3.6`.

Границы применимости: стенд измеряет только свойства мультиплексора. Реальная скорость дополнительно ограничена каналом, SSH и потерями. Проверка тех же цифр через настоящий SSH и агент лежит в [e2e-window](../e2e-window/README.md).
