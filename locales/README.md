# Переводы интерфейса

`en.json` — общий английский словарь десктопа, Android / Android TV и iOS.
Исходная русская строка служит ключом и запасным текстом. Подстановки имеют вид
`{0}`, `{1}`; в переводе можно менять их порядок, но нельзя терять аргументы.
Адреса, имена серверов и приложений, команды и секреты аргументами не переводятся.

Каждый клиент сохраняет язык отдельно от сетевой конфигурации. По умолчанию
используется русский. Смена языка не перезапускает сетевой движок.

Новые сообщения добавляйте через `t` (React) / `tr` (Kotlin, Swift), а затем
добавляйте перевод в словарь. Технические журналы сохраняют исходные сообщения:
это нужно для диагностики, поиска кодов ошибок и сопоставления с сервером.
