# Форматы официальных источников

Минимальные структурированные фрагменты, проверенные 27 ноября 2026 года.
Это фикстуры для регрессионных тестов, а не источник актуальных цен.

- `ovh.source`: публичный каталог OVHcloud IE, точный `vps-2025-model1`,
  помесячное продление, установка и варианты обязательства отдельно.
- `itldc.source`: сериализованные Astro props одной карточки AMS NVMe VDS 1G.
- `timeweb.source`: минимальный граф Nuxt/devalue с Cloud MSK 15.
- `firstvds.source`: `script[data-tariffs]`, SSD и NVMe одного названия.
- `iphoster.source`: карточка VPS-NVE-S, валюта и месячная/годовая цена.
  Сессионные поля страницы не сохраняются.
- `vultr.source`: обычный, бесплатный и IPv6-only тарифы; локации и пагинация.
- `hetzner.source`, `hetzner-ipv4.source`: Price API, CLOUD_140/NBG1 и CLOUD_21/ALL.
- `hetzner-page.source`: карточка CPX02 без SVG; резервная HTML-цена намеренно
  отличается от API-цены и не должна участвовать в расчёте.

Адреса источников заданы в `scripts/update-hosting-catalog.py`. В тестах
изменяются валюта, число совпадений и доступность источника: изменения не
должны превращать цену в ноль или обновлять дату прежних фактов.
