Нужные программы — через свой сервер

Secret Tunnel ведёт трафик выбранных приложений через ваш SSH-сервер, если нужно — цепочкой через промежуточный. Трафик остальных программ идёт напрямую.

macOS, Windows и Android. Нужен свой сервер с SSH: подойдёт любой недорогой VPS на Linux.

Условия использования. Используйте Secret Tunnel для подключения к серверам и ресурсам, к которым у вас есть право доступа. Соблюдайте применимое законодательство, в том числе установленные в России ограничения доступа к информации.

Что умеет

Ваш SSH-сервер, ваш ключ, ваш выбор программ. Никаких сторонних VPN-сервисов и подписок.

Туннель только для выбранных программ
Отметьте программы, которым нужен доступ к вашему сервису. Например, направьте через SSH тестовый клиент и мониторинг.
Цепочка серверов
Подключитесь к серверу через промежуточный SSH-шлюз, если так устроена ваша инфраструктура.
Звонки и игры тоже работают
Небольшой агент на сервере передаёт и TCP, и UDP внутри одного SSH-соединения. Отдельные порты на сервере открывать не нужно.
Вход по ключу, сервер проверяется
Подключение только по SSH-ключу. Строгая проверка ключа помогает обнаружить подмену сервера.
Статистика по приложениям
Сколько длились сеансы, через какой маршрут и страну, какие программы сколько трафика прогнали.

Что такое SSH

SSH (Secure Shell) — протокол защищённого подключения к удалённому серверу. Secret Tunnel использует его, чтобы передавать трафик выбранных программ до вашего сервера в зашифрованном виде.

Проверка сервера

При первом подключении сверьте отпечаток ключа сервера с данными из панели хостинга или от администратора. Режим «Строго» сверяет ключ сервера при каждом подключении.

Вход по ключу

Сервер хранит публичный ключ. Клиент подтверждает, что у него есть приватный ключ, с помощью цифровой подписи. Приватный ключ остаётся на вашем устройстве.

Границы защиты

SSH шифрует трафик до вашего сервера и защищает его от незаметной подмены в пути. Дальнейший участок защищает протокол самого приложения, например HTTPS.
