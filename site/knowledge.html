База знаний

Всё о настройке: от аренды сервера до звонков через туннель. Ищите по любому слову — статьи отфильтруются, совпадения подсветятся. Настраиваете вместе с ChatGPT или Claude? Дайте ассистенту ссылку на пошаговую инструкцию для ИИ — в ней точные команды и правила безопасности.

Начало

Как это устроено

Secret Tunnel держит одно SSH-соединение с вашим сервером и пропускает через него трафик выбранных программ. В интернет этот трафик выходит уже с сервера: сайты видят адрес и страну сервера, а не ваши.

  • Сервер — ваш VPS с доступом по SSH. Можно поставить промежуточный сервер, тогда соединение идёт «компьютер → промежуточный → сервер выхода».
  • Ключ — файл SSH-ключа на вашем устройстве. Паролей приложение не хранит.
  • Агент — небольшая программа на сервере. Через неё идут TCP и UDP: звонки, игры, QUIC. Встроенному SSH она обязательна; без неё работает только системный OpenSSH и только по TCP.
  • Локальный прокси — SOCKS5-порт на вашем компьютере, например 127.0.0.1:1080. Через него идёт выбранный трафик, его же можно указать в браузере вручную.
  • Перехват — направляет в туннель отмеченные программы целиком, без настройки прокси в каждой. Всё остальное идёт напрямую.

Сервер

Подойдёт любой VPS на Linux x86_64 с доступом по SSH: Ubuntu, Debian и другие. Хватит самого простого тарифа — нагрузку создаёт только ваш трафик.

  • Страна сервера — это страна, из которой вы будете «выходить» в интернет.
  • Можно сменить стандартный порт SSH (например, на 2222) — в приложении он указывается в профиле сервера.
  • Отдельный пользователь без прав администратора — хорошая привычка. Агенту sudo не нужен.
  • Если до зарубежного сервера напрямую медленно или нестабильно, добавьте промежуточный сервер ближе к вам. Как связать их, — в статье Серверы и цепочки.

SSH-ключ

Создайте ключ на компьютере. На вопрос о пароле ключа дважды нажмите Enter. macOS и Linux, Терминал:

mkdir -p ~/.ssh && chmod 700 ~/.ssh
ssh-keygen -t ed25519 -f ~/.ssh/secret-tunnel -C "secret-tunnel"

Windows, PowerShell (без папки .ssh ключ не сохранится):

New-Item -ItemType Directory -Force $env:USERPROFILE\.ssh | Out-Null
ssh-keygen -t ed25519 -f $env:USERPROFILE\.ssh\secret-tunnel -C "secret-tunnel"

Добавьте публичную часть на сервер. Порт и пользователя замените своими:

ssh-copy-id -i ~/.ssh/secret-tunnel.pub -p 2222 user@203.0.113.10

На Windows вместо ssh-copy-id:

type $env:USERPROFILE\.ssh\secret-tunnel.pub | ssh -p 2222 user@203.0.113.10 "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

Проверьте вход:

ssh -i ~/.ssh/secret-tunnel -p 2222 user@203.0.113.10 'echo ok'

Для цепочки серверов публичную часть того же ключа добавьте на оба сервера: приложение входит на каждый одним и тем же ключом.

Приватный ключ (secret-tunnel без .pub) никому не отправляйте. Ключи с паролем (passphrase) пока не поддерживаются.

Агент на сервере

Агент нужен встроенному SSH (он выбран по умолчанию): через него идут и TCP, и UDP. Без агента подключение остановится с ошибкой AGENT_MISSING; системный OpenSSH работает без агента, но только по TCP. Агент запускается по SSH на время подключения, не требует открытых портов, служб и sudo.

  1. Скачайте серверный архив со страницы релизов: SecretTunnel-X.Y.Z-server-linux-x86_64.tar.gz.
  2. Скопируйте его на сервер и распакуйте: 
    scp -P 2222 SecretTunnel-*-server-linux-x86_64.tar.gz user@203.0.113.10:
ssh -p 2222 user@203.0.113.10
mkdir -p st-agent && tar xzf SecretTunnel-*-server-linux-x86_64.tar.gz -C st-agent
cd st-agent
  3. Установите: sh install-server-agent.sh. Установщик проверит архитектуру и контрольную сумму, сохранит прежнюю версию и положит агент в ~/.local/bin.

Проверка: ~/.local/bin/secret-tunnel-agent --capabilities выводит версию агента и "tcp":true,"udp":true. Откат к предыдущей версии: sh install-server-agent.sh --rollback. Обновляйте агент вместе с приложением: у них общий номер версии, слишком старый агент приложение отклонит с понятной ошибкой.

В цепочке агент нужен только на сервере выхода.

Отпечаток сервера

Приложение проверяет, что подключается к вашему серверу, а не к подменённому. На компьютере используются записи из ~/.ssh/known_hosts — те же, что у обычного ssh. Проще всего один раз зайти на сервер из Терминала и подтвердить ключ.

Отпечаток можно сверить на самом сервере:

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

Режим проверки задаётся в профиле сервера: «Строго» (рекомендуется), «Запомнить новый» — доверить ключу при первом входе, «Не проверять» — только для отладки. На Android отпечаток показывается при первом подключении и сохраняется после вашего подтверждения.

Компьютер

Первое подключение

  1. Откройте «Серверы» и нажмите «Добавить». Укажите адрес, порт SSH, пользователя и выберите файл приватного ключа.
  2. Нажмите «Проверить SSH и агент»: приложение войдёт на сервер и проверит агента.
  3. В «Локальный прокси» оставьте профиль 127.0.0.1:1080 или создайте свой порт.
  4. На вкладке «Подключение» выберите сервер и прокси и нажмите «Подключить». Лента вверху покажет маршрут и страну выхода.

Дальше отметьте программы во вкладке «Приложения» или укажите прокси в браузере вручную.

Серверы и цепочки

Каждый профиль сервера хранит адрес, порт, пользователя и ключ. Поля:

Подключаться черезПромежуточный сервер. «Напрямую» — без него. Чтобы идти через RU, сначала добавьте RU отдельным профилем, затем выберите его здесь в профиле сервера выхода.
Проверка ключа хостаСтрого, запомнить новый или не проверять. Подробнее — в статье Отпечаток сервера.
Таймаут подключенияСколько ждать ответа сервера при входе.
Проверка связи и пропускиКак часто проверять, жив ли сервер, и после скольких пропусков переподключаться.

Цепочка в списке серверов выглядит как «RU → France». В неё входит любое количество звеньев: каждый профиль может указывать свой промежуточный сервер. Один и тот же сервер можно держать и напрямую, и в цепочке — двумя профилями — и переключаться одним выбором.

Через промежуточный сервер обычно выше стабильность и отдача, а напрямую — скачивание. Сравните оба варианта на вкладке «Скорость».

Локальный прокси

Пока туннель подключён, на вашем компьютере работает SOCKS5-прокси, по умолчанию 127.0.0.1:1080. Он принимает подключения только с этого компьютера, пароль не нужен.

Его можно указать в любой программе, которая умеет SOCKS5: в настройках сети Firefox, в расширении FoxyProxy, в Telegram. Включите «проксировать DNS через SOCKS», чтобы и имена сайтов разрешались на сервере.

Можно завести несколько профилей с разными портами и переключаться между ними на вкладке «Подключение».

Выбор программ

  1. Подключите туннель.
  2. Откройте «Приложения» и отметьте нужные программы. Поиск работает по названию; «Добавить .app» — для программ из нестандартных папок.
  3. Нажмите «Включить перехват». После изменения списка — «Применить выбор».
  4. Перезапустите отмеченные программы: перехват действует на новые соединения.

Вспомогательные процессы программы (у Discord их пять) отмечаются вместе с ней. На macOS приложение ещё и следит за процессами, которые программа запускает, например node или python у ChatGPT. Они получают своё правило за секунду, без разрыва соединений. Список подхваченных показывается вверху вкладки.

Если какая-то программа выбранного приложения всё же пошла мимо туннеля, появится предупреждение с кнопкой «Направить через туннель».

Перехват не включает «аварийный выключатель»: если туннель упадёт, новые соединения могут пойти напрямую.

macOS и ProxyBridge

Выбор программ на macOS работает через подписанное сетевое расширение ProxyBridge.

  1. Установите ProxyBridge 4.1.2 для macOS в папку «Программы».
  2. При первом включении перехвата разрешите расширение: Системные настройки → Основные → Объекты входа и расширения → ProxyBridge → сетевое расширение. Подтвердите добавление сетевой конфигурации.
  3. Закройте окно самого ProxyBridge: Secret Tunnel управляет им сам.

Если включён Clash или другой VPN в режиме TUN, оставьте в настройках «SSH мимо других VPN». DNS выбранных программ всё равно идёт через туннель, поэтому подмена адресов (fake-IP) в Clash им не мешает.

Windows

  • Рекомендуется установщик windows-x64-setup.exe: в нём приложение, компонент перехвата и WebView2. Переносной .zip требует уже установленный WebView2.
  • Для выбора программ запускайте Secret Tunnel от имени администратора.
  • Приложение пока без коммерческой подписи, поэтому Windows может предупредить о неизвестном издателе. Сверьте файл с SHA256SUMS.txt из релиза.
  • Настройки хранятся в %APPDATA%\secret-tunnel.

Доменные правила

Только на Windows: вместо программ можно направлять в туннель отдельные сайты по шаблону домена, а некоторые — наоборот, напрямую. Домен определяется по обычному DNS, поэтому при DoH/DoT в браузере точность ниже. На macOS используйте выбор программ.

Экран подключения

Лента сверху показывает путь: этот компьютер, промежуточные серверы, сервер выхода и страну. Ниже — внешний IP (скрыт, пока не нажмёте глаз), текущие скачивание и отдача, пинг до сервера, объём за сеанс и график за последние минуты. Боковая панель повторяет главное, видна на любой вкладке.

Статистика

Каждое подключение — сеанс: время, длительность, маршрут, страна выхода, объём трафика и программы, которые его прогнали. Вспомогательные процессы сворачиваются в своё приложение. Период выбирается сверху: сегодня, 7 или 30 дней, всё время.

«Без перехвата» — трафик программ, которые сами настроены на локальный прокси, например браузер с FoxyProxy. Статистика хранится только на этом компьютере; её можно очистить.

Скорость

Вкладка измеряет то, что получат программы. Сверху выбирается путь и сервис:

  • Через туннель или Без туннеля — тот же тест по обычному соединению компьютера, для сравнения. Без туннеля тесты работают, даже если туннель отключён.
  • Cloudflare или LibreSpeed — у LibreSpeed выбирается публичный сервер, который быстрее всего отвечает на этом пути.
БыстрыйПинг, загрузка и отдача в один поток, ≈15 с.
ПолныйВсё по очереди: пинг, UDP, один и шесть потоков, отдача, короткие запросы, ≈50 с.
Ширина канала8 потоков вниз и 4 вверх и пинг под нагрузкой.
Как браузер60 коротких запросов, каждый по новому соединению: насколько быстро открываются страницы.
СмешанныйДлинные загрузки, короткие запросы и пинг одновременно.
Задержка и UDP30 пингов и 30 DNS-запросов по UDP: важно для звонков и игр.
M-Lab NDT7Методика M-Lab: по 10 секунд загрузки и отдачи одним соединением.

Если пинг под нагрузкой сильно выше обычного, очередь раздувается — звонки во время загрузок будут прерываться. Перед каждым замером приложение определяет адрес и страну выхода; в истории видно, шёл ли замер напрямую, через один сервер или цепочкой.

M-Lab публикует результаты вместе с IP-адресом в открытом наборе данных. Без туннеля DNS-замер может перехватить другой VPN (Clash отвечает сам за доли миллисекунды) — такое значение не сравнивайте с туннелем.

Журнал

Внизу окна. Переключатели оставляют нужное: события, соединения, ошибки, служебные записи (по умолчанию скрыты). Соединение выглядит так: «туннель · Telegram → api.telegram.org :443». Повторы подряд сворачиваются в одну строку с числом.

Кнопка с глазом скрывает IP-адреса, в том числе при копировании — удобно для скриншотов и обращений в поддержку. Кнопка «{ }» показывает подробности диагностики.

Android

Установка и подключение

  1. Скачайте .apk со страницы релизов и установите. Android попросит разрешить установку из этого источника.
  2. Откройте «Серверы», добавьте сервер и импортируйте свой приватный ключ через выбор файла. Ключ хранится зашифрованным в Android Keystore.
  3. Нажмите «Подключить». Приложение покажет отпечаток сервера: сверьте его и подтвердите. Затем Android попросит разрешение VPN.

Кнопка «Создать отдельный ключ телефона» заведёт новый ключ только для этого телефона и сама добавит его на сервер. Так телефон можно отключить, не трогая ключ компьютера.

Выбор приложений

Во вкладке «Приложения» отметьте нужные: через VPN пойдут только они, остальные — напрямую. Поиск работает по названию и имени пакета. После изменения списка переподключитесь.

Android разрешает только один активный VPN: если включён другой, сначала остановите его.

Профиль трафика

Расширенные параметры — в редакторе прокси, применяются при следующем подключении ко всем звеньям цепочки.

  • Профиль трафика: «Сбалансированный» подходит большинству, «Голос» сильнее защищает звонки, «Максимальная скорость» для загрузок.
  • Очередь: «Стандартная» для повседневной работы.
  • Окно UDP: 1 МиБ и 512 датаграмм в обе стороны хорошо работают для звонков и QUIC.

Цепочка на телефоне

Добавьте оба сервера. В настройках сервера выхода выберите промежуточный вместо «Прямое подключение». Ключ телефона должен быть добавлен на оба сервера.

Если что-то не так

Частые проблемы

Сервер отклонён по ключу хостаСервер ещё не известен или ключ сменился. Зайдите на сервер из Терминала, сверьте отпечаток (статья Отпечаток сервера).
Агент отклонёнНа сервере старая версия агента. Установите агент из того же релиза, что приложение.
Программа идёт мимо туннеляПерезапустите её: старые соединения не перехватываются. Проверьте предупреждения вверху вкладки «Приложения» и журнал с фильтром «Соединения».
Discord завис на обновленииОбновите приложение до 0.3.19 или новее: DNS выбранных программ теперь идёт через туннель, и проверка обновлений проходит.
Тест скорости показал нольCloudflare мог временно ограничить большие загрузки. Приложение переключается на запасной источник само; выберите LibreSpeed или повторите позже.
Медленно через цепочкуСравните прямой маршрут и цепочку на вкладке «Скорость» и выберите лучший для своих задач.

Если не помогло, скопируйте журнал (с выключенным показом IP) и создайте обращение в Issues на GitHub.

Что хранит приложение

  • Настройки и профили — ~/.config/secret-tunnel/config.json на macOS и %APPDATA%\secret-tunnel\config.json на Windows. Ключи не копируются: хранится только путь к файлу.
  • Статистика сеансов и история замеров скорости — рядом с настройками, только на этом компьютере.
  • Журнал живёт в памяти и очищается при выходе.
  • Никакой телеметрии. Сетевые запросы, кроме вашего туннеля, — только тесты скорости и определение страны выхода, когда вы их запускаете.

Ничего не нашлось. Попробуйте другое слово или спросите в Issues.
